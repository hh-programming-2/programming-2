# Unit testing

> _"Unit Testing is a software testing technique used to verify individual units of source code, such as methods, functions, or classes, in isolation. It ensures that each unit behaves as expected according to its requirements."_
>
> [Unit Testing. GeeksforGeeks.](https://www.geeksforgeeks.org/software-testing/unit-testing-software-testing/)


This week, we will get familiar with JUnit unit testing and write our own unit tests for existing code.
